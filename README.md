# baozi-club
SillyTavern 擴展 - 小圈子分享

## 📱 2.0：滿屏小手機

打開就是滿屏的桌面（`desktop.js`）：時鐘、農曆、天氣、老公此刻（點一下他會往下過）、這個月玩了幾則、今日推薦／力推、下一個節日、聊天室最新；底部分頁列「桌面／指令庫／聊天／相簿／設定」。

## ✨ 2.5：模型自己做新排版

「✨ 讓模型設計」改成模型直接寫一張 HTML/CSS 卡片（`htmlcard.js`）：句子用空位、club 填原文；清掉 script 和外部網址；在 shadow DOM 排一次檢查（超出、漏句、對比、字太小），不合格叫它重做一次，再不行退回六款骨架。轉圖片用 SVG foreignObject，字體只抓用到的分塊包成 data:。預覽可以寫一句「想要的感覺」。

## 🥟 2.4：小包子

右下角的浮動按鈕換成小包子（`xiaobaozi.js`，像素畫）：平常豆豆眼、偶爾眯眼笑，晚上 10 點到 6 點睡著冒泡。每天第一次打開 tt 從蒸籠冒出來打招呼——一帆可以翻牌子（翻到誰就打開誰的聊天），米米可以把劇情時間推進到現在（填進輸入框、不送出）；節日當天會祝節日。設定可以關打招呼、也可以叫他出來。

## ⭐ 2.3：整樓收藏、跟隨酒館主題

- 選取模式點到哪幾樓，按「⭐ 收藏整樓」就整樓存起來（連樓裡的圖），桌面的「⭐ 收藏」翻得到，只有自己看得到
- 設定 →「🌈 主題」：🥟 包子奶油／🍷 跟隨酒館（用酒館主題的 SmartTheme 顏色），存在這支手機上

## ✨ 2.2：讓模型設計排版

設定 →「✨ 排版模型（自訂 API）」可以存好幾組 OpenAI 相容的 API（`aidesign.js`，金鑰只存在手機上）。截圖預覽按「✨ 讓模型設計」，模型讀選的句子，挑六款骨架之一、決定配色字體和標題；再按一次換一款。不會記成預設。

## 🎨 2.1：截圖六款排版

截圖預覽上面一排可以換排版：對話泡泡、書頁摘抄、拍立得、電影字幕、古風直排、信箋、電影票根（`templates.js`，canvas 畫的），會記住上次用的。字體（宋體、楷體、毛筆字）從大包子轉送的 Google Fonts 載。

## 🍞 跟大包子連線（2.0.0）

包子club 現在完全靠 Discord 上的大包子，不再連 Firebase：

1. Discord 打 `/club 登入`（一帆打 `/club 登录`），拿到一組 10 分鐘有效的登入碼
2. 打開包子club，輸入登入碼（大包子的網址已經內建）
3. 「📖 大包子指令庫」：全部／沒玩過／玩過／喜歡／熱門／黑名單，
   「沒玩過」會照現在開著的角色卡來篩；⭐ 收藏、🚫 拉黑、☑️ 記玩過都會同步到 Discord
4. 舊指令：Discord 打 `/club 搬家`，大包子自己去舊的 Firebase 讀，先預覽再搬
5. 首頁的「☀️ 今日推薦」跟 Discord 早上那 10 則同一份；標題列的 🎲 照設定隨機抽一則
6. 指令點一下就在原地展開，「▶️ 拿去玩」會把指令填進輸入框（不送出）
7. 展開一則按「💌 推給她」可以附一句話推給對方；對方的 🔔 會亮紅點（設定裡可以關掉 Discord 私訊）
8. 送出小劇場指令時自動記上「這個角色玩過」（可以復原）；包子裡沒有、又像指令的（開頭 `$`、或有「暫停當前劇情」「生成番外小劇場」）會問要不要存。設定裡可以關
9. 「📸 截圖／分享圖」：在聊天上點句子選起來（以。！？為一句；每樓有「全選這樓」；點圖片是選那張圖），做成一張排版好的長圖或分享原圖；可以發到 DC、只存不發、存到手機。存過的都在「🖼️ 相簿」（`shots.js`）
10. 「💬 聊天」：跟 Discord 的一個頻道即時互通，你在這裡說的話會用你的名字和頭像出現在 Discord（1.8.0）

`bot.js` 是跟大包子講話的那一半。吐槽、分享對話、成員牆之後在大包子上重做；
Firebase 上的舊資料沒有刪。

## 🀄 簡繁介面

介面跟著 tt 的語言：tt 是簡體就顯示簡體。介面字都用繁體寫，畫面畫好後自動轉（`i18n.js`）；
指令標題、內容、題材、聊天訊息這些她們自己寫的東西標了 `data-raw`，不會被轉。
加了新的繁體字沒轉到的話，跑 `python tools/build_i18n.py` 重新產生對照表。
