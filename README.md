# baozi-club
SillyTavern 擴展 - 小圈子分享

## 🍞 跟大包子連線（1.6.0）

指令庫改跟 Discord 上的大包子共用同一份：

1. Discord 打 `/club 登入`（一帆打 `/club 登录`），拿到一組 10 分鐘有效的登入碼
2. 打開包子club，輸入登入碼（大包子的網址已經內建）
3. 首頁的「📖 大包子指令庫」：全部／沒玩過／玩過／喜歡／熱門／黑名單，
   「沒玩過」會照現在開著的角色卡來篩；⭐ 收藏、🚫 拉黑、☑️ 記玩過都會同步到 Discord
4. 舊指令：設定 → 「📦 把 Firebase 的指令搬進大包子」

`bot.js` 是跟大包子講話的那一半。吐槽、分享對話、成員牆暫時還在 Firebase。
